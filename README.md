# Techyon 2026 — Hackathon Project

A collaborative repository for our 24-hour hackathon build.

## Structure
- `frontend/` — frontend application
- `backend/` — backend API and services
- `ai-module/` — AI/ML experiments, inference and model integration
- `docs/` — problem statement, architecture and API contracts

## Branch workflow
- `main` — stable, demo-ready version
- `dev` — shared integration branch
- `frontend`, `backend`, `ai-module` — individual work branches, created when assignments are finalised

Technology stack and setup instructions will be added after the problem statement is announced.
